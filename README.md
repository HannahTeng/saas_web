# Flowact website

Source for [flowact.net](https://flowact.net): Flowact, Inc. builds AI agents that work inside the systems a company already runs.

Next.js 14 · Tailwind · deployed on Vercel.

```bash
npm install
npm run dev
```

The use-case scenes live in `components/UseCases/` (markup, scoped CSS, and the animation engine).
